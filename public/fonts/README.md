# Fonts

The application self-hosts two open-source font families. The unmodified font
files and their SIL Open Font License 1.1 texts come directly from Google Fonts.

| Family | Authors | Source | License |
| --- | --- | --- | --- |
| Atkinson Hyperlegible Next | The Atkinson Hyperlegible Next Project Authors | [Google Fonts](https://github.com/google/fonts/tree/main/ofl/atkinsonhyperlegiblenext) | [OFL.txt](atkinson-hyperlegible-next/OFL.txt) |
| Bricolage Grotesque | The Bricolage Grotesque Project Authors | [Google Fonts](https://github.com/google/fonts/tree/main/ofl/bricolagegrotesque) | [OFL.txt](bricolage-grotesque/OFL.txt) |

[sources.json](sources.json) records each file's pinned source URL and SHA-256
checksum. Browsers load the bundled fonts without contacting an external service.
