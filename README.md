# Live Subtitles

**简体中文** · [English](README.en.md) · [繁體中文（香港）](README.zh-HK.md)

**一台电脑开启同声字幕，观众扫码选择自己的语言。**

A CryoZeroLabs project · [Follow @cryozerolabs on X](https://x.com/cryozerolabs)

精彩的分享，不该停在语言这一关。

当讲者与听众使用不同的语言，听众需要跟上内容，讲者需要保持节奏。Live Subtitles 为现场提供实时原文与译文，让字幕跟着讲话逐句推进，让观众通过手机参与同一场交流。

从现场大屏到手机屏幕，从实时字幕到会后录音与 SRT，一场交流的内容可以被看见、被带走、被继续使用。

## 让语言切换，不再打断交流

讲者还在往下说，听众却可能停在上一句话。一个细节没跟上，后面的背景、问题和判断就容易连着错过；等到会后补听录音，现场提问和共同确认的机会已经过去。

Live Subtitles 为讨论加上一条持续更新的文字线索：原文保留表达，译文帮助理解，字幕随着讲话逐句上滚。听众可以对照阅读、回看上下文，再回到最新内容，让理解和讨论发生在同一时间。

技术分享、社区活动、跨语言会议，都可以把字幕带进现场，让使用不同语言的参与者跟上同一场讨论。

## 一场活动，连接两块屏幕

| 组织者的电脑 | 听众的手机 |
| --- | --- |
| 展示原文与所选译文，投屏即可成为现场字幕大屏 | 扫描会议二维码，浏览器直接打开观看页 |
| 手动开始收音，按现场节奏暂停、继续或结束 | 在中文、English、粵語之间直接切换 |
| 字幕按句成组上滚，未定稿内容原处更新 | 独立选择语言，回看前文或一键回到最新 |

组织者准备好一场会议，听众用自己的屏幕跟随。手机与电脑连接同一局域网，扫码即可进入这场交流。

## 内容不会随着散场结束

结束会议后，讲话成为可以继续使用的内容素材。

- **回顾讨论**：在会议历史中对照原文与译文，找回当时的表达和上下文。
- **带走素材**：下载会议包，一次获得 WAV 录音，以及原文、中文、英文、粤语四份 SRT。
- **继续创作**：将录音与字幕交给后续整理、剪辑和字幕制作，让一场分享延伸为更多内容。

会议记录、录音和字幕保存在运行服务的电脑上，可在历史中回看、下载和删除。

## 模型由你选择，会议由你掌握

Live Subtitles 通过 OpenAI 兼容接口连接语音识别和字幕翻译服务。你可以为两项能力分别选择模型，也可以共用一套服务连接，让模型组合适配自己的语言、活动和工作流程。

当前版本支持中文、英语和粤语。如需其他语言，可自行微调翻译提示词、语言选项与字幕输出，并选用支持目标语言的模型。

设置中分别填写 **Base URL、API Key、模型**，翻译服务还可以直接复用识别服务的地址和 Key。Key 由本地后端管理，服务配置与会议内容各自保存，切换模型也能沿用熟悉的字幕界面。

创建会议时填写名称与可选描述，将分享主题、产品名和专业术语作为本场识别与翻译的背景。

## 把它带到你的下一场活动

准备 Node.js 20+、支持麦克风与 AudioWorklet 的现代浏览器，以及可用的语音识别和文本翻译服务。下载源码并进入项目目录，运行：

```sh
npm ci
npm start
```

打开 **[localhost:8090](http://localhost:8090)**，完成这几步：

1. 在“设置”中填写识别和翻译服务的 Base URL、API Key 与模型。
2. 创建会议，填写名称，进入字幕页。
3. 点击“开始收音”，允许麦克风权限；按现场节奏暂停或继续。
4. 让听众连接同一 Wi-Fi，扫码打开手机字幕，自行选择语言。
5. 活动结束时确认保存，在会议历史中回看或下载录音与 SRT。
